# Problem set 1: rating the AEB item

The questions are in `problem.py`; write your answers in `answers.py`, then commit and push.
Every push runs the checks (tab *Actions*, workflow *Check answers*): each question is reported as passed or
failed, and a failed check shows a hint and the course notebook section to revisit. To check locally:

```bash
pip install -r requirements.txt
python -m pytest -rA
```

Do not edit `problem.py` or `test_answers.py`; your instructor grades with the original versions.
