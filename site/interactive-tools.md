---
title: Interactive tools
---

These calculators run entirely in your browser and use exactly the same tables and formulas as the tested Python
package [`avsafety`](toolkit.md); CI checks the two against each other. Open a tool full screen for the best
experience on a phone.

::::{grid} 1 1 2 2
:::{card} ASIL calculator
:link: https://milinpatel07.github.io/Autonomous-Driving_AI-Safety-and-Security/tools/asil.html
Severity × exposure × controllability → ASIL, with decomposition options (ISO 26262-3, -9).
:::
:::{card} TARA risk calculator
:link: https://milinpatel07.github.io/Autonomous-Driving_AI-Safety-and-Security/tools/tara.html
Attack potential, attack vector or CVSS v3.1 → feasibility → risk value and CAL (ISO/SAE 21434).
:::
:::{card} RSS safe distance
:link: https://milinpatel07.github.io/Autonomous-Driving_AI-Safety-and-Security/tools/rss.html
Responsibility-Sensitive Safety minimum gap, TTC, headway and DRAC.
:::
:::{card} How many miles?
:link: https://milinpatel07.github.io/Autonomous-Driving_AI-Safety-and-Security/tools/miles.html
Failure-free distance needed to demonstrate a target rate (Kalra & Paddock, 2016).
:::
::::
