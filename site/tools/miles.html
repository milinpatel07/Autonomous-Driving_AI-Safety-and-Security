How many miles to show it is safe?

If failures follow a Poisson process, observing k failures in n miles demonstrates a rate below λ with confidence C only when n ≥ χ²C, 2(k+1) / (2λ). With zero failures this is n = −ln(1−C)/λ. The numbers explain why road testing alone cannot validate an automated driving system.
