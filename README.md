# Autonomous Driving: AI Safety and Security

A detailed, structured learning resource covering perception systems, functional safety, cybersecurity, and AI safety for autonomous vehicles. Aligned with ISO 26262, ISO 21448 (SOTIF), ISO/SAE 21434, and ISO/PAS 8800.

**Author:** [Milin Patel](https://github.com/milinpatel07) · Hochschule Kempten — University of Applied Sciences

---

## Overview

This repository provides **34 Jupyter notebooks** and **3 professional templates** organized into 7 progressive modules. Each notebook is self-contained and includes detailed explanations, working Python code, and visualizations.

- **01 Perception Systems:** Camera, LiDAR, Radar, and AI object detection.
- **02 Failure Analysis:** Real-world AV failures and adversarial robustness.
- **03 Functional Safety:** ISO 26262 methodology (HARA, ASIL).
- **04 SOTIF:** ISO 21448 and performance limitations.
- **05 Cybersecurity:** ISO/SAE 21434 threat modeling (TARA).
- **06 AI Safety:** Uncertainty quantification and trustworthy AI.
- **07 Integration & Deployment:** V2X, Explainability, and regulations.

## Getting Started

1. **Clone the repo:** `git clone https://github.com/milinpatel07/Autonomous-Driving_AI-Safety-and-Security.git`
2. **Install dependencies:** `pip install -r requirements.txt`
3. **Launch Jupyter:** `jupyter lab`

All notebooks are also executable in Google Colab via the provided badges.
